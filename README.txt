HERBERT MULLER — PORTFOLIO WEBSITE

Files:
- index.html       Main page
- education.html   Education subpage
- skills.html      Skills and languages subpage
- cv.html          CV subpage
- css/style.css    Shared styling and animations
- js/script.js     Parallax scroll effect
- assets/          Uploaded hero background image

PREVIEW:
Open index.html in a browser. Keep the folder structure unchanged so the pages
can find the stylesheet, JavaScript and image.

PUBLISH WITH GITHUB PAGES:
1. Upload all files and folders inside this package to the root of your
   GitHub repository (not just index.html).
2. In the repository, open Settings > Pages.
3. Choose Deploy from a branch, select main and /(root), then Save.
4. Open the published GitHub Pages URL. The navigation buttons link between
   the four pages.

You can add contact information and employment experience later.
